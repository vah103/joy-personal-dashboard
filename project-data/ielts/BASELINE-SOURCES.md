# IELTS baseline sources · 1–2 August 2026

The Joy IELTS baseline uses only official IELTS materials. The direct links are also attached to their matching tasks in `program-2026.json`.

## Official source hub

- [IELTS Academic sample test questions](https://www.ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test)

## Direct baseline materials

- [Listening computer practice](https://demo-ielts.inspera.com/player/?assessmentRunId=131012334&context=exam) — four parts, 40 questions.
- [Academic Reading computer practice](https://demo-ielts.inspera.com/player/?assessmentRunId=131013388&context=exam) — three passages, 40 questions.
- [Academic Writing computer practice](https://demo-ielts.inspera.com/player/?assessmentRunId=131013741&context=exam) — Task 1 and Task 2.
- [Speaking sample tasks PDF](https://ielts.org/cdn/ielts-sample-tests/ielts-speaking-sample-tasks-2023.pdf) — Parts 1, 2 and 3.

## Baseline rules

- Do not preview questions, prompts, recordings or answers before starting.
- The computer practice interface is not timed, so use an external timer.
- Complete Listening and Reading without pausing, replaying or using a dictionary.
- Complete Writing without ChatGPT or correction tools; request feedback only after both responses are finished.
- Complete Speaking as one continuous mock and keep the first recording as the baseline evidence.
